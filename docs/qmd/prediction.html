SECTION 01

Model Specification模型规格

target Dependent Variable因变量

The target variable is churn_probability, a continuous value ranging from 0 to 1 that represents each customer's likelihood of leaving the platform. Because this is a continuous outcome rather than a binary label, we treat the prediction task as a regression problem using regularized linear models. This approach preserves the granularity of the original probability values, allowing the model to distinguish between customers at 15% churn risk and those at 85% churn risk — a distinction that would be lost in a simple binary classification framework.

目标变量为 churn_probability，一个范围在0到1之间的连续值，代表每位客户离开平台的可能性。由于这是连续结果而非二元标签，我们将预测任务视为使用正则化线性模型的回归问题。这种方法保留了原始概率值的粒度，使模型能够区分15%流失风险和85%流失风险的客户——这种区分在简单的二元分类框架中会丢失。

SECTION 02

Regularization Methods正则化方法

With 21 features in the model matrix, ordinary least squares (OLS) regression risks overfitting — fitting noise in the training data that does not generalize to new customers. Regularization addresses this by adding a penalty term to the loss function that discourages large coefficients. We use the glmnet package in R, which efficiently fits both Lasso and Ridge regression via coordinate descent and selects the optimal penalty strength through cv.glmnet() with 10-fold cross-validation.

在模型矩阵中有21个特征的情况下，普通最小二乘法（OLS）回归存在过拟合风险——即拟合训练数据中无法推广到新客户的噪声。正则化通过向损失函数添加惩罚项来抑制过大的系数。我们使用R中的 glmnet 包，通过坐标下降法高效拟合Lasso和Ridge回归，并通过 cv.glmnet() 的10折交叉验证选择最优惩罚强度。

Lasso (L1 Regularization)

Primary model for feature importance特征重要性主模型

Lasso adds the sum of absolute values of coefficients as a penalty term: λ × Σ|βj|. This creates a powerful effect — as λ increases, coefficients of less important variables are shrunk to exactly zero, effectively removing them from the model.

This property makes Lasso our primary model for feature selection. By examining which variables survive at different λ values, we can identify the minimal set of customer attributes that drive churn prediction. Analysts can use the λ slider in the Shiny app to visually observe how the model progressively simplifies.

  • •Automatic variable selection via coefficient zeroing
  • •Sparse, interpretable models at higher λ
  • •Ideal for answering: "Which features matter most?"

Lasso将系数的绝对值之和作为惩罚项：λ × Σ|βj|。这产生了强大的效果——随着λ增大，不重要变量的系数被压缩至恰好为零，有效地将其从模型中移除。

这一特性使Lasso成为我们特征选择的主模型。通过检查在不同λ值下哪些变量存活，我们可以识别驱动流失预测的最小客户属性集。分析师可以使用Shiny应用中的λ滑块直观地观察模型如何逐步简化。

  • •通过系数归零实现自动变量选择
  • •在更高λ下产生稀疏、可解释的模型
  • •适合回答："哪些特征最重要？"

Ridge (L2 Regularization)

Validation model for comparison用于比较的验证模型

Ridge adds the sum of squared values of coefficients as a penalty: λ × Σβj². Unlike Lasso, Ridge never shrinks coefficients to exactly zero — instead, it pulls all coefficients proportionally toward zero, retaining every variable in the model.

We use Ridge as a validation model to cross-check the Lasso results. If the Ridge model achieves similar predictive accuracy while retaining all variables, it confirms that the features Lasso selected are indeed the most important ones. If Ridge significantly outperforms Lasso, it suggests that many small-contribution features collectively improve prediction.

  • •Retains all variables with proportional shrinkage
  • •Better when many features contribute modestly
  • •Serves as benchmark to validate Lasso feature selection

Ridge将系数的平方值之和作为惩罚：λ × Σβj²。与Lasso不同，Ridge从不将系数压缩至恰好为零——而是将所有系数按比例向零拉近，保留模型中的每个变量。

我们使用Ridge作为验证模型来交叉检查Lasso结果。如果Ridge模型在保留所有变量的同时达到类似的预测精度，则确认Lasso选择的特征确实是最重要的。如果Ridge显著优于Lasso，则表明许多小贡献特征共同提升了预测效果。

  • •保留所有变量并进行比例缩减
  • •当多个特征有适度贡献时表现更佳
  • •作为基准来验证Lasso的特征选择
tune The λ Parameter: Controlling Model Complexityλ 参数：控制模型复杂度

The regularization parameter λ (lambda) is the single most important hyperparameter in both Lasso and Ridge regression. It controls the trade-off between fitting the training data closely and keeping the model simple:正则化参数λ（lambda）是Lasso和Ridge回归中最重要的超参数。它控制着紧密拟合训练数据与保持模型简洁之间的权衡：

λ = 0 (No regularization)λ = 0（无正则化）

Equivalent to ordinary least squares. All features retained with full coefficients. Risk of overfitting.等同于普通最小二乘法。所有特征以完整系数保留。存在过拟合风险。

λ = λ.min (Optimal)λ = λ.min（最优）

Selected by 10-fold CV. Minimizes prediction error. Balances bias and variance for best generalization.通过10折交叉验证选出。最小化预测误差。平衡偏差与方差以获得最佳泛化能力。

λ → ∞ (Maximum)λ → ∞（最大值）

Lasso: all coefficients zero (null model). Ridge: all coefficients near zero. Maximum bias, minimum variance.Lasso：所有系数为零（空模型）。Ridge：所有系数接近零。最大偏差，最小方差。

We use cv.glmnet() with 10-fold cross-validation to identify two key λ values: λ.min (the λ that minimizes mean cross-validated error) and λ.1se (the largest λ within one standard error of the minimum, yielding a more parsimonious model). Both models are pre-trained offline, saved as .rds files, and loaded at Shiny startup for instant predictions.我们使用 cv.glmnet() 的10折交叉验证来识别两个关键λ值：λ.min（使平均交叉验证误差最小化的λ）和 λ.1se（在最小值一个标准误差范围内的最大λ，产生更简约的模型）。两个模型均离线预训练，保存为 .rds 文件，在Shiny启动时加载以实现即时预测。

SECTION 03

Feature Engineering特征工程

Beyond the raw independent variables, we engineer three derived features that capture higher-order customer behavior patterns. These features are computed during data preparation and added to the model matrix alongside the original variables. Each encodes a specific business hypothesis about what drives churn.除原始自变量外，我们还构造了三个衍生特征以捕捉更高层次的客户行为模式。这些特征在数据准备阶段计算并与原始变量一起添加到模型矩阵中。每个特征编码了关于流失驱动因素的特定商业假设。

category product_diversity_ratio

active_products / 5

(max possible products = 5)

Normalizes the number of active products to a 0–1 scale. A customer with only 1 of 5 products (ratio = 0.20) is less embedded in the platform ecosystem than one using all 5 (ratio = 1.0). Higher product diversity implies higher switching costs, which should reduce churn risk. This feature captures the "stickiness" dimension that raw product count alone does not convey at a normalized scale.将活跃产品数量归一化到0–1的范围。仅使用5种产品中1种的客户（比率=0.20）在平台生态系统中的嵌入度低于使用全部5种的客户（比率=1.0）。更高的产品多样性意味着更高的转换成本，应能降低流失风险。该特征捕捉了原始产品计数在归一化后无法传达的"粘性"维度。

support_agent ticket_resolution_gap

support_tickets_count × (1 − resolved_tickets_ratio)

Measures the absolute number of unresolved support tickets. A customer with 10 tickets and 50% resolution has a gap of 5 unresolved tickets, while one with 2 tickets and 50% resolution has a gap of only 1. This interaction term captures the frustration dimension: it is not just about having tickets, but about having tickets that remain unsolved. Higher values signal service delivery failures that may push customers to churn.衡量未解决工单的绝对数量。拥有10张工单且50%解决率的客户有5张未解决工单，而拥有2张工单且50%解决率的客户仅有1张。这个交互项捕捉了挫败感维度：重点不在于是否有工单，而在于工单是否悬而未决。较高的值表明服务交付失败，可能推动客户流失。

sentiment_dissatisfied satisfaction_gap

base_satisfaction − satisfaction_score

Computes the difference between the customer's baseline (initial) satisfaction and their current satisfaction score. A positive gap indicates that the customer's satisfaction has declined over time, which is a stronger churn signal than low absolute satisfaction alone. A customer who dropped from 9 to 5 is more at risk than one who was always at 5 — the trajectory of dissatisfaction matters as much as the level.计算客户基线（初始）满意度与当前满意度评分之间的差值。正差值表明客户的满意度随时间下降，这比单纯的低绝对满意度是更强的流失信号。从9分降至5分的客户比一直是5分的客户面临更高风险——不满意的轨迹与水平同样重要。

Cross-Validation Performance交叉验证性能

The CV performance plot displays λ vs. Mean Squared Error (MSE) across the 10-fold cross-validation. Two critical λ values are marked with vertical dashed lines:

  • •λ.min — The λ that achieves the lowest cross-validated MSE. This is the model with the best predictive accuracy.
  • •λ.1se — The largest λ within one standard error of the minimum. This yields a sparser, more parsimonious model with slightly higher error but better interpretability.

The curve typically shows a U-shape: error decreases as λ increases from zero (reducing overfitting), hits a minimum, then rises again (underfitting). The flat region between λ.min and λ.1se indicates that the model is robust to the exact λ choice within this range.

交叉验证性能图显示10折交叉验证中的λ与均方误差（MSE）关系。两个关键λ值用垂直虚线标记：

  • •λ.min — 达到最低交叉验证MSE的λ。这是预测精度最佳的模型。
  • •λ.1se — 在最小值一个标准误差范围内的最大λ。产生更稀疏、更简约的模型，误差略高但可解释性更好。

曲线通常呈U形：随着λ从零增大误差先减小（减少过拟合），达到最小值后再上升（欠拟合）。λ.min和λ.1se之间的平坦区域表明模型对该范围内的确切λ选择具有鲁棒性。

equalizer

Residual Distribution残差分布

A histogram of residuals (actual − predicted) assesses whether the model's errors are well-behaved. For a good regression model, residuals should be:

  • •Centered at zero — The model does not systematically over- or under-predict.
  • •Approximately normal — Most errors are small, with few large errors in either direction.
  • •Symmetric — Errors are equally distributed above and below zero, with no heavy tails.

Skewed or heavy-tailed residuals would suggest that the linear model assumption is violated and alternative approaches (e.g., quantile regression or non-linear models) should be considered.

残差（实际值 − 预测值）直方图评估模型误差是否表现良好。对于一个好的回归模型，残差应该：

  • •以零为中心 — 模型不会系统性地高估或低估。
  • •近似正态 — 大多数误差较小，两个方向的大误差很少。
  • •对称 — 误差均匀分布在零的上下两侧，无重尾。

偏斜或重尾残差表明线性模型假设被违反，应考虑替代方法（如分位数回归或非线性模型）。
