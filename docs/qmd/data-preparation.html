SECTION 01

Data Sources数据来源

The COFINFAD dataset is composed of two relational tables linked by customer_id. Together they capture both the static profile of each customer and their full year of transactional behaviour. All data is synthetically generated to mirror a Colombian financial institution's retail banking portfolio.COFINFAD数据集由两个通过 customer_id 关联的关系表组成。它们共同捕获每位客户的静态档案及其全年交易行为。所有数据均为合成生成，以模拟哥伦比亚金融机构的零售银行业务组合。

Data Cleaning & Imputation数据清洗与缺失值填补

healing

Missing Value Treatment缺失值处理

The credit_utilization_ratio column contained the only meaningful missingness in the dataset:credit_utilization_ratio 列是数据集中唯一存在有意义缺失的字段：

Missing values缺失值 37.5%

18,263 of 48,723 records48,723条记录中有18,263条

Strategy: Median imputation grouped by income_bracket策略：按 income_bracket 分组进行中位数填补

Why not mean? The mean is sensitive to extreme values prevalent in financial data. Grouped median preserves the distributional shape within each income tier without being pulled by outliers.为何不用均值？均值对金融数据中常见的极端值敏感。分组中位数可以在每个收入层级内保持分布形状，而不会被异常值拉偏。

search_insights

Outlier Detection异常值检测

Transaction amounts exhibit heavy right-skew with extreme high-value entries that can distort distance-based algorithms.交易金额呈明显右偏分布，极端高值会扭曲基于距离的算法。

warning Extreme values detected in transaction amounts在交易金额中检测到极端值
Strategy策略 Winsorization at 1st / 99th percentile在第1/第99百分位进行缩尾处理
Applied to应用于 Clustering features only仅聚类特征

Note: Raw values are retained for EDA so that box plots and histograms reflect the actual distribution. Winsorized values are used exclusively in the clustering pipeline where Euclidean distance would otherwise be dominated by outliers.注意：原始值保留用于探索性数据分析，以便箱线图和直方图反映实际分布。缩尾值仅用于聚类流程，否则欧氏距离将被异常值主导。

SECTION 04

Feature Engineering特征工程

Beyond the raw columns, we engineer derived features that capture latent behavioural signals not directly observable in the original data. These features are critical for both the clustering and prediction modules.除了原始列之外，我们还构建了衍生特征，捕获原始数据中不可直接观察到的潜在行为信号。这些特征对聚类和预测模块至关重要。

category

product_diversity_ratio

active_products / 5

Measures how broadly a customer uses the bank's product portfolio (savings, credit card, loan, insurance, investment). A ratio of 1.0 indicates full adoption; lower values flag single-product customers at higher churn risk.衡量客户使用银行产品组合的广度（储蓄、信用卡、贷款、保险、投资）。比率为1.0表示完全采用；较低值标记出流失风险较高的单产品客户。

support_agent

ticket_resolution_gap

support_tickets × (1 − resolved_ratio)

Quantifies unresolved service burden. A customer with many tickets and a low resolution rate has a high gap — a strong signal of dissatisfaction and potential churn.量化未解决的服务负担。工单多且解决率低的客户差距值高——这是不满和潜在流失的强烈信号。

sentiment_dissatisfied

satisfaction_gap

base_satisfaction − satisfaction_score

Captures the delta between a customer's baseline satisfaction (e.g., at onboarding) and their current score. A positive gap signals deteriorating sentiment over time.捕获客户基线满意度（如入网时）与当前评分之间的差值。正向差距表明情绪随时间推移而恶化。

show_chart

spending_volatility

sd(monthly) / mean(monthly)

The coefficient of variation of monthly transaction totals. High volatility indicates irregular spending patterns — potentially seasonal workers or customers with unstable financial behaviour.月度交易总额的变异系数。高波动性表明支出模式不规律——可能是季节性工人或财务行为不稳定的客户。

weekend

weekend_transaction_ratio

weekend_tx / total_tx

Proportion of transactions occurring on Saturday or Sunday. This behavioural timing feature distinguishes personal-use customers (higher weekend activity) from business-oriented ones.在周六或周日发生的交易比例。此行为时间特征区分了个人使用客户（周末活动较多）和商业导向客户。

SECTION 05

Standardization for Clustering聚类标准化

Clustering algorithms that rely on distance metrics (K-Means, hierarchical) are highly sensitive to variable scale. Without standardization, features measured in large units (e.g., transaction amounts in COP) would dominate the distance calculation, drowning out features with smaller numeric ranges (e.g., ratios between 0 and 1).依赖距离度量的聚类算法（K-Means、层次聚类）对变量尺度高度敏感。如果不进行标准化，以大单位衡量的特征（如以COP为单位的交易金额）将主导距离计算，淹没数值范围较小的特征（如0到1之间的比率）。

functions

Z-Score NormalizationZ-Score 标准化

z = (x − μ) / σ

Each value is centred at zero with unit variance每个值以零为中心，单位方差

Implemented via R's scale() function. This ensures every feature contributes equally to Euclidean and Manhattan distance calculations during cluster assignment.通过R的 scale() 函数实现。确保每个特征在聚类分配的欧氏距离和曼哈顿距离计算中贡献相等。
