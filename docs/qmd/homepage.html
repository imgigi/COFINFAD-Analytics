About This Project

COFINFAD Analytics is an interactive R Shiny application that transforms Colombia's fintech data into accessible, visual business intelligence. Built on a dataset of 48,723 customers and 3.16 million transactions, the app follows a three-stage analytical narrative: exploring transactional patterns through interactive EDA, segmenting customers via multi-method clustering, and predicting churn risk with regularized regression — all within a unified dashboard requiring no coding.

Exploratory & Confirmatory Data Analysis

Module 2

Customer Behavior Clustering

Segment 48,723 customers using K-Means, Hierarchical (Ward's D2), and PAM with 10 behavioral features. PCA scatter plots, elbow & silhouette diagnostics, and cluster profile radar charts.
