About This Project关于本项目

COFINFAD Analytics is an interactive R Shiny application that transforms Colombia's fintech data into accessible, visual business intelligence. Built on a dataset of 48,723 customers and 3.16 million transactions, the app follows a five-module analytical narrative: exploring transactional patterns through interactive EDA, confirming statistical hypotheses via ggstatsplot (CDA), segmenting customers via multi-method clustering, calibrating predictive models, and simulating churn scenarios with a What-If simulator — all within a unified dashboard requiring no coding.

COFINFAD Analytics 是一个交互式 R Shiny 应用程序，将哥伦比亚的金融科技数据转化为直观、可视化的商业智能。基于 48,723 名客户和 316 万笔交易数据，该应用遵循五模块分析叙事：通过交互式 EDA 探索交易模式、通过 ggstatsplot 验证统计假设（CDA）、通过多方法聚类细分客户群体、校准预测模型、以及使用 What-If 模拟器模拟流失场景——所有功能集成在统一仪表板中，无需编写代码。

Core Modules核心模块

我们的分析遵循五模块叙事逻辑：探索数据模式（EDA）、验证统计假设（CDA，使用 ggstatsplot）、细分客户群体（聚类）、校准预测模型、以及模拟流失场景（What-If）。

Module 1模块一

Exploratory & Confirmatory Data Analysis探索性与验证性数据分析

Separated into two dedicated tabs: EDA for high-level overview (time-series, Leaflet choropleth, distributions) and CDA for statistical hypothesis testing via ggstatsplot (ggbetweenstats with 4 test types, pairwise comparisons, ggcorrmat with hclust-reordered correlation matrix).

分为两个独立标签页：EDA 展示高层概览（时间序列、Leaflet 分级地图、分布图）和 CDA 进行统计假设检验（ggstatsplot 提供 ggbetweenstats 四种检验类型、成对比较、ggcorrmat hclust 重排序相关矩阵）。

Module 2模块二

Customer Behavior Clustering客户行为聚类

Segment 48,723 customers using K-Means, Hierarchical (Ward's D2), and PAM with 10 behavioral features. PCA scatter plots, elbow & silhouette diagnostics, hclust-reordered heatmaps, parallel coordinates, and dendrograms.

使用 K-Means、层次聚类（Ward's D2）和 PAM 方法，基于 10 个行为特征对 48,723 名客户进行细分。包含 PCA 散点图、肘部法与轮廓系数诊断图、hclust 重排序热力图、平行坐标图和树状图。

Module 3模块三

Churn Prediction & What-If Simulation流失预测与假设模拟

Split into two dedicated pages: Model Calibration (CV performance, variable importance, predicted vs actual, residuals) and What-If Simulator (adjust customer attributes via sliders, see prediction breakdown and sensitivity analysis in real time).

分为两个独立页面：模型校准（交叉验证性能、变量重要性、预测vs实际、残差分析）和 What-If 模拟器（通过滑块调整客户属性，实时查看预测分解和敏感性分析）。
