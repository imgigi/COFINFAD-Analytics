Observation 1 — Seasonal transaction volume patterns differ by transaction type

Transfer volumes exhibit pronounced year-end spikes, likely driven by holiday remittances and bonus-period spending. Withdrawal volumes show a more stable baseline with moderate monthly fluctuations. Payment transactions trend upward over time, reflecting growing digital adoption, while Deposit volumes remain comparatively steady, suggesting a consistent savings behavior across the customer base regardless of seasonal factors. These divergent temporal signatures indicate that any segmentation or churn model should account for transaction-type-specific seasonality rather than treating aggregate volume as a single feature.

Observation 3 — Customer demographics cluster geographically across Colombian regions

Departments with major urban centers — such as Bogotá (Cundinamarca), Medellín (Antioquia), and Cali (Valle del Cauca) — dominate in customer count and tend to exhibit higher average CLV, consistent with greater digital infrastructure and higher income levels. Conversely, departments in the Pacific and Amazonian regions show lower customer penetration but elevated average churn probabilities, suggesting that customers in less-served areas face barriers to sustained engagement. This geographic clustering implies that a one-size-fits-all retention strategy would be suboptimal; region-specific interventions should be informed by the map-level patterns surfaced here.

SECTION 04

Confirmatory Statistical Tests验证性统计检验

Exploratory visualizations suggest group-level differences, but confirming their statistical significance requires formal hypothesis testing. This section implements two classical parametric tests — one-way ANOVA for multi-group comparisons and Welch's t-test for pairwise comparisons — to rigorously evaluate whether observed differences in transaction behavior across customer segments are likely to reflect genuine population-level effects rather than sampling variability.

functions

ANOVA (One-Way)

Tests whether the means of a continuous variable differ significantly across three or more groups. Appropriate when comparing income brackets, customer segments, or regional groupings.

Test Output Metrics
F-statistic F(2, 9997) = 48.32
p-value p < 0.001 ***
η² effect size η² = 0.0096
Example Hypothesis

H0: Mean avg_tx_value is equal across all income_bracket groups (Low, Medium, High).

H1: At least one group mean differs significantly.

compare

Welch's T-test

Pairwise comparison between exactly two groups, robust to unequal variances. Used for focused comparisons such as acquisition channel effects or binary customer attributes.

Test Output Metrics
t-statistic t(4821) = −3.17
p-value p = 0.0015 **
Cohen's d d = 0.091
Example Hypothesis

H0: Mean avg_tx_value is equal for Organic vs. Referral acquisition channels.

H1: The two group means differ significantly.

Effect Size Interpretation Guide效应量解释指南

Statistical significance (p-value) indicates whether an effect exists; effect size indicates how large that effect is. Both are reported for each test.

< 0.01

< 0.06

< 0.14

≥ 0.14

For ANOVA: η² (eta-squared) thresholds shown above. For Welch's t-test: Cohen's d uses thresholds of 0.2 (small), 0.5 (medium), 0.8 (large).

Observation 2 — Transaction behavior varies significantly across income brackets and acquisition channels

The one-way ANOVA confirms a statistically significant difference in average transaction value across the three income brackets (F = 48.32, p < 0.001), though the effect size (η² = 0.0096) falls in the negligible-to-small range, indicating that income bracket alone explains less than 1% of the variance in transaction value. Welch's t-test comparing Organic versus Referral acquisition channels yields a significant result (t = −3.17, p = 0.0015) with a small Cohen's d of 0.091. Together, these findings suggest that while group membership does influence transaction behavior at a population level, the practical magnitude of these differences is modest — reinforcing the need for multivariate approaches (such as the clustering and prediction modules) rather than relying on any single demographic split.

SECTION 06

Shiny IntegrationShiny 集成

All visualizations and statistical tests in this module are designed to operate within a reactive R Shiny framework. The Shiny app provides a unified interface where users can adjust parameters through sidebar controls and immediately see updated outputs without writing any code. Below is a summary of the input controls and output panels that power the Exploratory Analysis module.

tune Input Controls输入控件

dateRangeInput — Date Range

Filters the transaction dataset to a user-specified observation window. Affects the time-series chart and all downstream aggregations. Default range spans the full dataset period.

checkboxGroupInput — Transaction Types

Toggles which transaction types (Transfer, Withdrawal, Payment, Deposit) are displayed on the time-series chart. All types are selected by default.

selectInput — Grouping Variable

Selects the categorical variable used to segment histograms and box plots (e.g., income_bracket, customer_segment, acquisition_channel). Controls demographic distribution panel.

selectInput — Test Variable & Statistical Test

Chooses which numeric variable to test and which test to apply (One-Way ANOVA or Welch's t-test). The test results panel updates reactively with formatted output.

selectInput — Map Metric

Switches the choropleth map between Customer Count, Average Churn Probability, and Average CLV. The color scale and legend update automatically.

dashboard Output Panels输出面板

plotlyOutput — Time Series

Renders the monthly transaction volume line chart. Reactively updates when the date range or transaction type filters change. Supports hover, zoom, and brush interactions natively.

plotlyOutput — Box Plot / Histogram

Displays the demographic distribution charts. Responds to changes in the grouping variable and numeric variable selectors. Includes jittered points overlay for box plots.

leafletOutput — Choropleth Map

Renders the interactive Colombia department map. Reactively re-colors when the map metric selector changes. Supports click events to display department-level detail popups.

plotlyOutput — Correlation Heatmap

Displays the 12×12 correlation matrix as an interactive heatmap. Static by default but supports hover inspection of individual r-values and variable pair labels.

uiOutput — Statistical Test Results

Dynamically renders formatted test output including test statistic, degrees of freedom, p-value with significance stars, and effect size with interpretation label. Updates when the test variable or test type changes.
