SECTION 01

Approach Overview方法概述

Running clustering algorithms on 48,723 records in real time is computationally prohibitive for an interactive Shiny app. Our solution: pre-compute all cluster assignments offline and let the app read results instantly.

speed

Why Pre-compute?为何预计算？

K-Means, hierarchical, and PAM all require iterative distance calculations across 48,723 observations. Even a single run of PAM can take 30+ seconds. With multiple k values, algorithms, and feature presets, live computation would make the Shiny app unusable.

inventory_2

What We Pre-compute预计算内容

k = 2 to 8 — cluster counts

3 algorithms — K-Means, Hierarchical (Ward's D2), PAM

3 feature presets — RFM, Full Behavioral, Engagement

63 combinations total stored in a single .rds file

SECTION 04

Cluster Evaluation聚类评估

Choosing the optimal number of clusters requires converging evidence from multiple validation methods. We combine three complementary approaches and enable side-by-side algorithm comparison.

show_chart

Elbow Method (WSS Plot)肘部法则（WSS图）

Plots total within-cluster sum of squares against k. The "elbow" — the point where adding more clusters yields diminishing returns in variance reduction — suggests the optimal k.

info WSS always decreases as k increases; the key is finding where the rate of decrease sharply flattens.
equalizer

Silhouette Analysis轮廓分析

Measures how similar each point is to its own cluster vs. neighboring clusters. The average silhouette width (ranging from −1 to 1) quantifies cluster cohesion and separation.

Close to 1.0 Well-clustered
Close to 0.0 On boundary
Negative Misclassified
how_to_vote

NbClust Consensus VotingNbClust 共识投票

The NbClust package evaluates up to 30 statistical indices (Calinski-Harabasz, Dunn, Gap, etc.) and tallies which k each index recommends. The k with the most "votes" is the consensus optimal.

info Majority-rule voting across 30 indices provides a more robust recommendation than any single metric alone.
compare_arrows

Side-by-Side Algorithm Comparison算法并列比较

For the same feature preset and k, users can compare how K-Means, Hierarchical, and PAM partition the data differently. Key comparison metrics:

check_circle Average silhouette width per algorithm
check_circle Cluster size balance (evenness)

A color-coded matrix showing standardized feature means per cluster. Red indicates above-average values; blue indicates below-average — making cross-cluster differences instantly scannable.
